**When to use:** Paste it after (or before) any rough prompt when you're not sure you've phrased the ask well. The model rewrites your prompt into a stronger one, aims at what you actually want rather than your literal wording, and takes the lead on the approach instead of waiting for you to specify everything. Good for design, planning, or any task where you know the goal but not the best way to ask.

**Source:** @EigenBraid on X (Oct 30 2026, 116 likes / 127 bookmarks), calling it "one of the very rare prompting tricks that is still useful over a year later." It quotes @elder_plinius's older post (Mar 28 2025, 3,275 likes / 3,217 bookmarks), whose screenshot shows the original go-one-meta-level-up trick, included below as a related variant.

## Prompt

```
Take my prompt and write a better version of it; 
do what I want, not what I say; 
you have permission to lead this design.
```

## Related: the original meta-level trick (@elder_plinius)

```
write a prompt for {insert-query-here} then answer it
```
