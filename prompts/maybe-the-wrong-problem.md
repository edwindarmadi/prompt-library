# Maybe the wrong problem

**When to use:** You’re deep in a solution and want the model to climb up to problem definition instead of polishing the current ask. Don’t solve yet.

**Note:** Workshopped from the dig find “Assume I’m solving the wrong problem…” (Adrian Hensler). Kept Edwin’s cleaner short version.

## Prompt

```
Here’s the problem I think I have: [problem].
Here’s how I’m solving it: [approach].
Assume I might be solving the wrong problem. What else could the real problem be, what makes you think that, and what should I be asking instead? Don’t solve yet.
```
