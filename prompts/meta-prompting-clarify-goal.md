# Meta-prompting (clarify the goal)

**When to use:** Before a fuzzy, open-ended AI task (research, strategy, complex writing) when the goal itself is unclear — thinking prompt first, task prompt second.

**Source:** [Antony Evans](https://antonyevans.com/blog/engineering/c073-meta-prompting/)

## Prompt

```
Help me think through what I’m actually trying to achieve with [task]. Ask me questions until the goal is clear enough that a sharp answer would be obvious.
```
