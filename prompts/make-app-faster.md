# Make the app faster

**When to use:** Paste into a coding agent (e.g. Claude Code) on an app that feels slow: startup, screen opens, content loading, scrolling. It finds the real bottleneck, fixes it, and benchmarks each fix.

**Source:** [Emanuele Di Pietro (@emanueledpt)](https://x.com/emanueledpt/status/2110053042452312250) (Oct 13, 2026, 381 likes, 876 bookmarks). He says it ran for 3 hours on his app and found 4 performance bugs he'd missed.

## Prompt

```
Your job is to make this app faster. Improve the startup time, how fast each screen opens, how fast its content loads, and the scrolling, so everything feels lighter and older content loads faster. Find where the real performance gap is, apply the fixes, and benchmark before and after each one to see if it actually works or not.
```
